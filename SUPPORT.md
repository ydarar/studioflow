# Support

## Where to ask for help

1. Usage and troubleshooting
- Open a GitHub issue with reproduction steps and relevant command output.

2. Bug reports
- Open a GitHub issue including expected vs actual behavior and relevant artifacts (`.runs/<run-id>/run.json`, `events.jsonl`).

3. Security issues
- Follow `SECURITY.md` and report privately.

4. Conduct issues
- Follow `CODE_OF_CONDUCT.md` and report privately to maintainers.

## Self-serve references

- `README.md`: quick project orientation
- `docs/day0-runbook.md`: first successful run
- `docs/cli-reference.md`: command and flag semantics
- `docs/configuration.md`: env vars and precedence
- `docs/testing-manual-smoke.md`: release gate checklist
