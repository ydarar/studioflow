# Governance

## Maintainers

Maintainers are responsible for roadmap direction, release management, and enforcement of project policies.

## Decision process

- Routine decisions are handled through pull request review.
- Significant changes (CLI contracts, schema contracts, runtime behavior) require explicit rationale in PR descriptions.

## Release and compatibility policy

- Releases are cut by maintainers.
- Breaking changes must be documented in `CHANGELOG.md`.
- Documentation updates are required in the same PR for contract and workflow changes.

## Escalation

If reviewer consensus cannot be reached, maintainers make the final decision based on determinism, safety, and operator clarity.
